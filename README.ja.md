## 何を調べ、何が分かったか

「Aの教え方を変えると、後でBを学ぶ効率が変わるか」を調べました。制御された合成課題では、促進・阻害・中立の転移が観測され、共有表現や出力側の座標への介入が結果を変えました。

自然文を含む小型モデル実験でも、**英語を知る教師の内部表現を、日本語由来の入力上でStudentに教える**と、後続英語の成績・区間学習コストが改善する方向が得られました。ただし対象はVim/TeXのソフトウェア翻訳文です。

**「日本語のテキストを学ぶだけで英語が5%速くなる」とは示していません。** 教師には英語由来情報があり、5%という数値境界は測定間隔に依存します。

|---|---|---|
| R1・教師損失係数1.0 | **登録FAIL**。英語区間の平均節約率6.3521%、日本語損失悪化1.1355% | 日本語保持上限1%を超過 |

| seed18500・state–signal確認 | **BLOCKED / NOT COUNTED** | 正確な依存コード3ファイルが未公開 |

R2登録節約率の中央値は5.8849%、範囲0.7798〜10.5482%。平均の記述的95%区間は3.08〜7.37%です。節約率は英語の共通性能区間の更新数であり、教師作成や日本語の準備学習を含む総費用ではありません。日本語保持は**英語を学習する前**に判定されており、英語学習後の保持保証ではありません。

測定モデルは141,056パラメータ、2層Transformer、幅64、4 heads、固定256-byte語彙、context128 byte、batch16。自然R2はAMD EPYC 9V74・float32・PyTorch 2.10.0+cpu・1 thread/job、9月9日の診断はIntel Xeon Platinum 8573C。CPUクロックは固定せず、実時間性能は主張しません。

## 公開記録を検証する

リポジトリ直下でPython 3.11〜3.13を使います。GPU・PyTorch・ネット接続は不要です。

```bash
python scripts/verify_publication.py
```
