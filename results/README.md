# Result summaries

Compact CSV summaries used by the repository claim ledger.

- `evidence_summary.csv`: cross-phase result table with PASS/FAIL status.
- `surrogate_all_realization_topology.csv`: early structural-surrogate topology correlations.
- `matched_wrong_exact_tests.csv`: source-distance/entropy/margin-matched target-vs-wrong map.
- `natural_ja_en_blended5_confirmatory_tests.csv`: Japanese -> English 95/5 pilot.

These are summary artifacts, not raw data dumps. Large checkpoints, raw per-step logs, and third-party corpora are intentionally excluded.
